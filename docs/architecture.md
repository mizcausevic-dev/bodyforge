# Architecture

BodyForge treats embodied AI oversight as a safety-governed operations problem.

## Inputs

- Robot zone and task
- Human proximity
- Battery state
- Override readiness
- Safety policy assignment
- Event severity
- Policy triggers
- Handoff chains
- Resolution states

## Core idea

Physical agents need more than telemetry. They need:

- clear safety states
- replayable event provenance
- visible override and handoff chains
- operator-readable containment guidance

## Outputs

- Fleet risk overview
- Event replay lane
- Incident board
- API payloads for safety systems, supervisors, and digital twins
